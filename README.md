## 關於我

嗨，我是 Willy。

大學念的是企管和資工雙主修，所以我習慣同時從兩個角度看產品：一邊想「這東西有沒有人要、要怎麼賣」，一邊想「這東西做不做得出來、要怎麼做」。

**我做過的事**

- 🚀 在學校帶過 **3 次創業專案**，擔任 team lead，從需求探索一路做到 MVP v1～v2
- 🧩 在新創公司當**產品助理**，負責產品測試、用 Figma 規劃產品流程，也做競品調查
- 📈 寫過企業**行銷策略提案**，也協助公司與上市公司合作，提案進軍新市場

**我正在做的事**

- 🤖 上「產品經理 × AI」課程，學習用 **Coding Agent** 把想法直接做成產品
- 🛠️ 準備完成個人專題與團隊專題，做好會放上來
- 📚 準備 AI PM 相關證照，同時加強英文

**接下來**

課程結束後，我想投入 **AI 產品**相關的工作。如果你的團隊需要一個懂商業、也能跟工程師溝通的 PM，歡迎找我聊聊。
